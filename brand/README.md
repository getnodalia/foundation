# Nodalia brand

The Nodalia logo, mark and wordmarks, and the app icons the website shows, kept here so every
repository and page can take them from one place. They come from
[nodalia-web](https://github.com/getnodalia/nodalia-web) (`assets/`), which still uses its own copies.

| File | What |
|---|---|
| `logo.svg` | The logo: the N mark on its dark rounded square |
| `nodalia-mark.svg` | The mark on its own |
| `nodalia-wordmark.svg` | The wordmark as the website header draws it |
| `nodalia-wordmark-black.svg`, `nodalia-wordmark-white.svg` | The wordmark for light and dark backgrounds (README headers use these with `<picture>`) |
| `nodalia-wordmark-badge.svg` | The wordmark on a badge that reads on light and dark pages |
| `web/favicon.svg`, `web/favicon.ico`, `web/apple-touch-icon.png` | The website's tab and home-screen icons |
| `app-icons/*.png` | The app icons shown on getnodalia.com. Each app's own repository keeps its full icon set |

Link to a file at a fixed commit, for example
`https://raw.githubusercontent.com/getnodalia/foundation/<commit>/brand/nodalia-wordmark-white.svg`.

## Use

These are Nodalia's own marks, not open-source assets: they are not covered by this repository's
MIT or Apache-2.0 licence. Use them unmodified, and only to name or link to Nodalia and its apps.
A fork or a modified version of an app removes them. When an app ships one of these files, it lists
it in its own `ATTRIBUTION.md` as a Nodalia mark.
